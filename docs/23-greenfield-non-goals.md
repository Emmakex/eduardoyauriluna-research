# Greenfield foundation non-goals

This foundation deliberately does not:

- scan a legacy WordPress installation;
- infer page-builder layouts;
- import arbitrary existing content;
- decide redirects for old URLs;
- auto-adopt pages whose Theme contract is wrong;
- make Gutenberg responsible for Research layouts;
- bypass the Manager Executor to perform blueprint writes.

These exclusions are architectural guarantees, not missing features of the Greenfield workflow.
