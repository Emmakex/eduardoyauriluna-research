# Greenfield Manager — next microphases

1. **Runtime mode contract** — explicit Greenfield default and isolated Migration capabilities. Implemented in this milestone.
2. **Greenfield orchestrator** — one bounded service that composes Theme-owned Page and academic Resource creation without legacy discovery.
3. **Academic resource creation parity** — normalize direct creation contracts for Insights, Publications/Outputs, Projects, Software and Datasets.
4. **Initial site blueprint** — declarative ES/EN Research website blueprint that can create the known page/resource skeleton from a clean WordPress installation.
5. **SEO/GEO hydration** — hydrate structured copy, metadata, relationships and schema-facing fields from the blueprint without Gutenberg layout ownership.
6. **Readiness verification** — verify routes, language pairing, canonical structures, Theme rendering and required academic metadata.
7. **Admin/API surface** — expose Greenfield bootstrap status and explicit actions while keeping Migration tooling separate.

Each microphase must keep the Theme as frontend authority and must preserve bounded validation, verification and rollback for write safety.
