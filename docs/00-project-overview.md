# Project Overview

## Mission

Create a durable research identity and publication platform for **Eduardo Jose Yauri Luna**, with **eduardoyauriluna.com** as the canonical public hub.

The project has two simultaneous goals:

1. Strengthen Eduardo's academic profile for doctoral applications and future research activity.
2. Serve as a real-world implementation case for the reusable **Researcher preset** in the SEO/GEO Theme + Manager.

## Scope

This repository owns:

- Research identity and positioning
- Academic biography and research statement
- Research lines and project descriptions
- Publication records and working papers
- Research software and datasets
- Academic identifiers and connector configuration
- Site-specific WordPress code/configuration
- Decisions and roadmap for eduardoyauriluna.com

This repository does **not** own reusable product logic such as generic ORCID connectors, generic publication CPT implementations or the reusable Researcher preset. Those belong in the Theme/Manager product repository.

## Website principles

- Academic first, not commercial-first
- English primary, Spanish secondary
- Fast and accessible
- Structured for Google Scholar discovery
- DOI and ORCID aware
- Schema.org structured data
- No fabricated credentials, publications or affiliations
- Clear distinction between peer-reviewed, preprint, technical report, software and dataset outputs

## Success criteria for 2027 doctoral applications

The project should aim to have:

- Public ORCID profile
- Academic website live
- Research statement
- Academic CV / CVN
- Google Scholar profile when eligible/useful
- Zenodo profile and DOI-backed outputs
- OpenAlex identity resolved
- Research software and/or dataset published where appropriate
- 3–5 credible research outputs, clearly labelled by type and review status
- A coherent doctoral research proposal and supervisor outreach package
