# Greenfield foundation — definition of done

The foundation is done when the codebase can answer these questions explicitly without inspecting a legacy website:

1. Which scenario is active? `greenfield`.
2. May the Manager create directly from the Theme contract? Yes.
3. Must it discover/map legacy structures first? No.
4. Can a declarative Research blueprint be validated? Yes.
5. Can the blueprint be preview-compiled without mutation? Yes, beginning with Theme-owned Pages.
6. Does existing unknown contract drift get silently adopted? No; it is blocked.
7. Are writes still protected by existing Manager plans/Executor? Yes.

The next phase is execution of the Page portion of the blueprint and then compiler parity for academic resources.
