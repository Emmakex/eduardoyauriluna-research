# Greenfield milestone acceptance

The milestone is acceptable when:

- Research resolves to `greenfield` on a clean or unset Manager installation.
- Direct Theme-contract creation remains available.
- Greenfield reports no requirement for legacy discovery or legacy mapping.
- Migration must be selected explicitly before Greenfield orchestration is blocked.
- Existing Resource Services remain the implementation path for Pages, Insights, Outputs, Projects, Software and Datasets; the orchestrator does not duplicate them.
- Theme compatibility remains a prerequisite for direct creation.
- Syntax/static CI protects the scenario boundary.
- Existing plan validation, snapshots, verification and rollback remain available as write-safety mechanisms and are not described as migration requirements.

The next implementation milestone is a declarative Greenfield site blueprint built on this boundary.
