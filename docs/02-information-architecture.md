## Content models

### Researcher Profile

- Canonical name
- Headline
- Short bio
- Long bio
- Location at city/region level only if intentionally public
- Research interests
- Keywords
- Current affiliation, only when factually valid
- Education
- Professional background relevant to research
- Academic identifiers
- Social/research profile links

### Publication

- Title
- Authors
- Publication year/date
- Output type
- Review status
- Abstract
- Venue
- DOI
- Canonical URL
- PDF
- Keywords
- Citation text / BibTeX
- ORCID-linked authors where available
- Zenodo record
- Related dataset
- Related software
- Structured metadata

Suggested output types:

- Journal article
- Conference paper
- Preprint
- Working paper
- Technical report
- Book chapter
- Poster
- Presentation

### Research Project

- Title
- Status
- Summary
- Research question(s)
- Methods
- Timeline
- Collaborators
- Related publications
- Related software
- Related datasets
- Ethics/privacy notes where relevant

### Research Software

- Name
- Description
- Repository URL
- Version
- Release date
- License
- DOI / Zenodo record
- CITATION.cff
- Documentation URL
- Related publication/project

### Dataset

- Title
- Description
- Version
- Date
- License
- DOI
- Repository
- Methodology
- Data dictionary
- Privacy/anonymisation statement where relevant
- Related publication/project

## Homepage composition

1. Researcher identity hero
2. Research focus
3. Selected research outputs
4. Current projects
5. Research software / datasets
6. Academic identifiers and profile links
7. Latest insights
8. Contact / collaboration

The visual language should communicate research rigor + advanced technology, not a commercial agency landing page.
